# Nightwell Chat Server v0.5.1

Windows-сервер Nightwell Chat без контейнеров. Python 3.12 + FastAPI + SQLite. **Отдельный сервис от Nightwell Music**.

## Запуск на Windows

1. Установите Python 3.12. Команда проверки: `py -3.12 --version`.
2. Распакуйте файлы поверх старого сервера Chat. **Не удаляйте `.env` и `data/`**.
3. Остановите старый Chat через `Stop_Nightwell_Chat.bat` или `Ctrl+C` в окне его запуска. Caddy и Nightwell Music не трогайте.
4. Дважды нажмите `Start_Nightwell_Chat.bat`. Он создаст `.venv`, установит зависимости и запустит сервер.
5. Проверьте `http://127.0.0.1:8009/health`.

Если сервер запускается впервые, BAT-файл сам создаст `.env` со случайным секретом. Не заменяйте его при обновлениях. Для резервной копии сохраняйте **вместе** `.env`, `data/nightwell_chat.db` и `data/media/`.

## Caddy

Сохраняйте ваш существующий `Caddyfile` для двух сайтов:

```caddyfile
music.nightwell.fun {
    reverse_proxy 127.0.0.1:8080
}

chat.nightwell.fun {
    reverse_proxy 127.0.0.1:8009
}
```

Nightwell Chat слушает **только** `127.0.0.1:8009`, а публичный доступ идёт через Caddy на HTTPS 443. Второй экземпляр Caddy не запускайте. Порт 8009 на роутере открывать не требуется.

## Что есть в API

- Регистрация/вход по телефону и паролю **без SMS**. Номер проверяется **только по формату**, а не на принадлежность владельцу.
- Сохранён прежний вход по логину и паролю. К существующему аккаунту можно привязать номер.
- Поиск по телефону только пользователей с добровольно включённой видимостью номера. Приложение должно запрашивать разрешение на контакты и отправлять лишь выбранный номер.
- Личные и групповые чаты, отправка сообщений, ответы, реакции, редактирование и удаление, история и статусы прочтения.
- Загрузка и получение аватарок, изображений и файлов. Максимальный размер вложения 15 МБ. Доступ к вложениям разрешён только участникам чата. Фотографии конвертируются в JPEG без EXIF.
- Аудиозвонки один на один: создание, принятие, отклонение, завершение, сигнализация WebRTC и отдельная HTTPS-страница соединения.

## Ограничения тестовой версии

- **Без SMS нет реальной проверки владельца номера.** Нельзя доверять телефонному номеру как подтверждённой личности.
- У звонков нет push-вызовов, поддержки в фоне, CallKit и своего TURN-сервера. На некоторых сетях WebRTC не соединится. Сам сервер не передаёт аудио, только сигналы установления связи.
- Нет сквозного шифрования сообщений, сканирования загруженных файлов и зрелой антиспам-системы.
- Один процесс SQLite/WebSocket, подходит прежде всего для небольшой тестовой аудитории, а не массового публичного запуска.
- Обновлённые iOS/Android-клиенты должны соответствовать этим эндпоинтам. Этот ZIP содержит только сервер.

## Проверка

В папке `server`, после установки зависимостей и с отдельной тестовой базой:

```powershell
$env:SECRET_KEY = 'local-test-secret-long-enough-only-for-tests'
$env:DB_PATH = "$env:TEMP\nightwell_test.sqlite"
..\.venv\Scripts\python.exe -m pytest -q
```

**Не запускайте тесты на рабочей базе.**
