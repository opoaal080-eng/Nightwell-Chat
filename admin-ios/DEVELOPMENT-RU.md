# «Развитие» в Nightwell Admin

Нативная вкладка iOS показывает стратегические материалы текстом, карточками и графиками. PDF или внешний просмотрщик не нужен. Материалы входят в приложение и доступны без подключения к Admin Bridge.

Первая запись — план развития Nightwell Music от 15.11.2026: все 20 разделов, распределение Free/Premium, 16 направлений развития, этапы на 24 недели, продвижение на 90 дней, метрики, бюджеты, риски и источники. Предложения и расчётная экономика отделены от фактической статистики. Прогресс выполнения не придумывается.

## Добавить следующий материал

1. Откройте `NightwellAdmin/DevelopmentResources/development-library.json`.
2. Добавьте объект в массив `documents`, сохранив `schemaVersion: 1`. Используйте отдельный стабильный `metadata.id`, дату `planDate` и название.
3. Полный читаемый материал хранится в `sections`. Блоки: `heading`, `paragraph`, `callout`, `table`; у таблицы число ячеек каждой строки должно совпадать с числом `headers`. У блока можно указать массив `links` с адресами источников.
4. Структурированные `freeBacklog`, `premiumBacklog`, `roadmap`, `marketing90days`, `budgets`, `economics` и `sources` питают специализированные экраны. Не смешивайте расчётные сценарии и реальные результаты. Для нового типа документа сохраните контракт модели или добавьте новую версию схемы с соответствующими экранами.
5. Соберите приложение. Новый материал появится в библиотеке вкладки; отдельный SwiftUI-экран для каждой записи не нужен.

Это поставляемая с приложением библиотека, а не серверная система совместного редактирования. Следующие изменения материалов входят в следующую сборку приложения. Изменения тарифов или серверных прав отсюда не применяются.

## Проверки

Workflow `Nightwell Admin iPhone IPA` выполняет проверки декодирования и формул, собирает нативное приложение, проверяет JSON внутри bundle и создаёт неподписанную IPA. Запуск: pull request с изменениями `admin-ios`, push в main или вручную в GitHub Actions.

Для проверки данных на Mac:

```sh
swiftc -parse-as-library admin-ios/NightwellAdmin/DevelopmentPlan.swift admin-ios/Tests/DevelopmentDataTests.swift -o /tmp/nightwell-development-tests
/tmp/nightwell-development-tests admin-ios/NightwellAdmin/DevelopmentResources/development-library.json
```

Для установки IPA нужна пользовательская подпись, как у предыдущих сборок Nightwell Admin. Проверка на физическом iPhone отдельно: пять вкладок, поиск, фильтры, графики, калькулятор, Dynamic Type, открытие источников и чтение без сети.
